# Geely Monjaro Car App

This is a minimal Android application project targeting the Geely Monjaro infotainment system running Android 9. The project demonstrates how to enable GPS programmatically and serves as a starting point for additional features such as Google services integration, multi‑display support, and climate control automation.

## Building
1. Ensure Android SDK and gradle are installed.
2. Run `./gradlew assembleDebug` inside the `car_app` directory.

## Features to extend
* Install Google services packages using root permissions.
* Transfer activities between driver, center, and passenger displays with three‑finger swipes.
* Automatically launch Google Maps on the driver display.
* Control AC and windows based on cabin temperature.
* Disable automatic engine start/stop and allow remote start.

This repository only contains a simple skeleton and does not include proprietary components or full implementations.
